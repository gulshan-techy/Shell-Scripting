# Bash Shell Scripting

This repository contains Bash/Shell Scripting programs for learning and practicing Linux scripting.

## Topics Covered

* Variables
* User Input
* Operators
* If-Else
* Elif
* Case Statement
* For Loop
* While Loop
* Until Loop
* Functions
* Arrays
* String Operations
* File Handling
* Basic Linux Automation

## Purpose

The purpose of this repository is to improve Bash scripting skills through simple programs, practice problems, and small automation tasks.

## Requirements

* Linux / Unix-based system
* Bash Shell

## Run a Script

```bash
chmod +x script.sh
./script.sh
```

Or:

```bash
bash script.sh
```
